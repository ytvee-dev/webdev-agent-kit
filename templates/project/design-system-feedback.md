# Draft Design System Field Feedback

**DRAFT — use only for an explicitly requested real-project pilot.** Keep the
filled record under host `.agents/project/`, with `publishable: false` and
`local_only: true`. Share a sanitized reproduction only when authorized.

- Kit tag/commit, client/version/model and selected conversational role:
- Exact prompt and pilot scope:
- Source type: local components/tokens / Figma library / both:
- Source revision, component/state/mode and installed package versions:
- Actual available capabilities and access limitations:
- Expected result and independently obtained source evidence:
- Actual actions, files/nodes changed and resulting evidence:
- Status: observed failure / observed pass / blocked / unrun / proposal:
- Failure stage: discovery / extraction / mapping / decision / write / verification:
- Effect details: owning layer, ancestors, stack, opacity, blur type, bindings:
- Minimal reproduction, repeat count and fresh-session result:
- Local instruction correction and before/after behavior:
- Counterexample where that correction should not apply:
- Rollback/recovery result and preserved consumer/instance behavior:
- Reusable rule candidate versus project-specific preference:
- Remaining gaps and owner acceptance decision:

A build proves buildability; a screenshot proves only its captured state.
Neither proves token bindings, variant structure, account access or automatic
synchronization. Keep failures, denied access and incomplete reads in the record.
Do not upload credentials, private source, customer designs or full tool traces.
